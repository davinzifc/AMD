# Plan de Implementación: Requerimientos 08-02-2026

## Context

El sistema de certificados crypto está en Fase 6 (completo). Se requieren 5 cambios:
1. **Enhancement 1**: CRUD de firmantes con imagen de firma en DB
2. **Enhancement 2**: Selección de firmante al generar PDFs
3. **US 1**: Reestructurar stepper de 4 a 5 pasos (nuevo paso "Seleccionar Tercero")
4. **Bug 1**: Limpiar estado entre iteraciones + botón "Cargar Nuevo Excel"
5. **Bug 2**: Arreglar exportación de PDF (muestra éxito pero no genera archivo)

**Orden de implementación**: E1 → E2 → US1 → Bug1 → Bug2

**Decisiones tomadas**:
- Imagen de firma: BLOB en SQLite (portable, simple)
- Selección de terceros: Multi-select con checkboxes

## Fase 1: Enhancement 1 — Base de Datos de Firmantes

### 1.1 Backend (Rust)

**Nueva migración**: `src-tauri/src/db/migrations/v002_create_firmantes.sql`
```sql
CREATE TABLE IF NOT EXISTS crypto_firmantes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nombre TEXT NOT NULL,
    cc_id TEXT NOT NULL,
    firma_imagen BLOB,
    firma_mime TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
- Imagen almacenada como BLOB directo (máx ~2MB, validado en frontend)
- `firma_mime` guarda el tipo MIME (image/png, image/jpeg) para reconstruir la imagen

**Registrar migración en**: `src-tauri/src/db/connection.rs` (agregar v002 al vec de migrations)

**Nuevo modelo**: `src-tauri/src/models/crypto/firmante.rs`

## Fase 2: Enhancement 2 + US 1 — Reestructuración del Stepper

### 2.1 Nuevo Step 2: Seleccionar Tercero

**Nuevo componente**: `src/app/tools/certificados-crypto/components/third-party-selector/third-party-selector.component.ts`
- Input: `transactions: RawTransaction[]`
- Output/Model: `selectedIds: string[]`
- Extraer valores únicos de `{id, third_name}` de las transacciones
- Tabla PrimeNG con checkboxes multi-select, 2 columnas: ID, THIRD_NAME
- Barra de búsqueda + contador de seleccionados

### 2.2 Step 3: Revisar Datos — Filtrado

- DataTableComponent recibe solo transacciones filtradas por los IDs del Step 2
- Computed signal: `filteredTransactions = transactions.filter(t => selectedThirdPartyIds.includes(t.id))`

### 2.3 Step 5: Resultados — Selector de Firmante

- Agregar dropdown de firmante (PrimeNG Select) en la toolbar de results-table
- Inyectar FirmanteService, cargar firmantes
- Validación: firmante + año + grupos requeridos para generar

### 2.4 Backend: Integrar Firmante en PDF

- `generate_pdfs` recibe `firmante_id: Option<i64>`
- `build_template_data()` agrega `firmante_nombre`, `firmante_cc_id`, `firmante_imagen` (base64 data URI)
- Fallback a `representante_*` de Empresa si no hay firmante

### 2.5 Template de Certificado

- Agregar imagen de firma en sección `.signature` (si existe)
- Usar datos del firmante en vez de representante

### 2.6 Reestructuración del Stepper (4→5 pasos)

1. Cargar Excel (value=1) — sin cambios
2. Seleccionar Tercero (value=2) — NUEVO
3. Revisar Datos (value=3) — filtrado por selección
4. Procesamiento (value=4) — sin cambios
5. Resultados (value=5) — con selector de firmante

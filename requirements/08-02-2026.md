## Mejoras (Enhancements)

### Enhancement 1: Base de Datos de Firmantes

**Descripción**:
Se requiere implementar una funcionalidad para gestionar múltiples firmantes en lugar de tener un único firmante predeterminado.

**Implementación**:
Crear una sección de gestión de firmantes en "Configuración de Usuario" siguiendo el mismo patrón de implementación utilizado para el registro de empresas.

**Campos Requeridos**:
- Nombre del firmante
- CC/ID (Cédula de Ciudadanía o Identificación)
- Imagen de la firma (archivo digital)

**Persistencia de Datos en Base de Datos**:
- Todos los datos de los firmantes deben almacenarse de manera permanente en la base de datos para garantizar su persistencia
- Las imágenes de las firmas también deben guardarse en la base de datos (como BLOB o mediante almacenamiento de archivos con referencia en BD)
- Se debe asegurar que los datos permanezcan disponibles entre sesiones y no se pierdan al reiniciar la aplicación
- Implementar un esquema de base de datos adecuado con tabla(s) para gestionar múltiples firmantes por usuario/empresa
- Garantizar que una vez almacenados los datos del firmante, estos persistan indefinidamente en la base de datos
- Las imágenes de firma deben quedar almacenadas en la base de datos junto con los demás datos del firmante

**Funcionalidad**:
Los usuarios deben poder agregar, editar y eliminar firmantes desde la configuración, manteniendo un repositorio de firmantes disponibles para la selección al momento de generar documentos.

---

### Enhancement 2: Selección de Firmante en Generación de Documentos

**Descripción**:
Antes de generar un documento, el sistema debe solicitar al usuario que seleccione qué persona está firmando el documento.

**Implementación**:
- Agregar un paso de selección de firmante en el flujo de generación de documentos
- Los datos del firmante seleccionado (nombre, CC/ID e imagen de firma) deben incluirse automáticamente en el documento generado
- La selección debe realizarse desde la base de datos de firmantes creada en Enhancement 1
- Los datos y la imagen deben recuperarse dinámicamente desde la base de datos al momento de generar el documento

## Bugs

### Bug 1: Persistencia de Datos entre Iteraciones

**Prioridad**: Alta

**Tipo**: Funcional

**Condición para Revisión**: Este bug debe revisarse y corregirse una vez que la US 1 esté completamente terminada.

**Descripción del Problema**:
- En el primer intento, cada step funciona correctamente y muestra los datos apropiados
- Al intentar hacer una nueva selección, los steps continúan mostrando la información de la primera selección
- Los datos de la iteración anterior permanecen en memoria/cache
- No existe un botón "Cargar Nuevo Excel" que permita:
  - Regresar automáticamente al Step 1
  - Limpiar el cache o datos en memoria
  - Reiniciar el flujo completamente

**Solución Esperada**:
- Implementar limpieza de datos entre iteraciones
- Agregar botón "Cargar Nuevo Excel" visible en todos los steps que:
  - Reinicie el flujo completo
  - Limpie toda la información almacenada en memoria/cache/estado
  - Redirija automáticamente al Step 1
  - Borre los datos del Excel previamente cargado
- Asegurar que cada nueva selección trabaje con datos frescos
- Implementar un mecanismo de limpieza de estado al cambiar entre iteraciones

**Pasos para Reproducir**:
1. Cargar un archivo Excel
2. Completar el flujo seleccionando datos específicos
3. Intentar hacer una nueva selección o cargar otro archivo
4. Observar que los datos de la primera iteración persisten

**Criterios de Aceptación**:
- El botón "Cargar Nuevo Excel" debe estar visible y funcional
- Cada nueva iteración debe comenzar con un estado limpio
- No debe haber datos residuales de iteraciones anteriores
- El flujo debe poder ejecutarse múltiples veces consecutivas sin problemas

### Bug 2: Fallo en Exportación de PDF

**Prioridad**: Alta

**Tipo**: Crítico

**Condición para Revisión**: Este bug debe revisarse y corregirse una vez que la US 1 esté completamente terminada.

**Descripción del Problema**:
- Al hacer click en el botón de exportar PDF, aparece un mensaje indicando que el PDF se generó exitosamente
- Sin embargo, no se exporta ningún documento
- El archivo PDF no se descarga ni se genera
- No hay evidencia de que el archivo se haya creado en el servidor o cliente

**Comportamiento Esperado**:
- Al hacer click en exportar PDF, el sistema debe generar efectivamente el documento
- El archivo PDF debe descargarse automáticamente o estar disponible para descarga
- El mensaje de éxito solo debe aparecer cuando el documento se haya generado y exportado correctamente
- El usuario debe poder guardar el PDF en su dispositivo

**Pasos para Reproducir**:
1. Completar el flujo de certificados crypto hasta el Step 5 (Resultados)
2. Hacer click en el botón "Exportar PDF" o similar
3. Observar que aparece mensaje de éxito
4. Verificar que no se descarga ningún archivo

**Criterios de Aceptación**:
- El PDF debe generarse correctamente con todos los datos
- El archivo debe descargarse automáticamente al hacer click
- El mensaje de éxito debe mostrarse solo después de la descarga exitosa
- En caso de error, debe mostrarse un mensaje de error apropiado
- El PDF generado debe incluir todos los datos del firmante (nombre, CC/ID e imagen de firma)
